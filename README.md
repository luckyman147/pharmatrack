# PharmaTrack

Pharmacy management system with an Angular frontend and a C# backend.

## Features

- User authentication (login / register)
- Pharmacy CRUD operations
- Visit management
- Delegate management
- Role-based access for different types of users

## Tech Stack

- **Frontend:** Angular
- **Backend:** C# / .NET
- **Database:** SQL Server

## Why This Project Stands Out

- **Complete system:** authentication, CRUD, visits, and delegate management
- **Structured backend:** C# / .NET with clear architecture patterns
- **Role-based:** different access levels for different users
- **Real-world use case:** built for pharmacy management
