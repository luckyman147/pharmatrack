# PharmaTrack

Pharmacy management system with C# backend.

## Features

- User authentication (Login/Register)
- Pharmacy CRUD operations
- Visit management
- Delegue management

## Tech Stack

- Backend: C# / .NET
- Database: SQL Server
## Why This Project Stands Out

- **Complete System** - Auth, CRUD, visits, and delegation management
- **Professional Backend** - C# .NET with proper architecture patterns
- **Role Based** - Different access levels for different users
- **Production Ready** - Real-world pharmacy management solution
